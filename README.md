# Bank Operations Widget

Виджет для обработки банковских операций: фильтрация по статусу, сортировка по дате, поиск по описанию, поддержка разных форматов файлов.

## Возможности

- Фильтрация транзакций по статусу (`EXECUTED`, `CANCELED`, `PENDING`).
- Сортировка транзакций по дате (ISO‑формат), по возрастанию или убыванию.
- Поиск транзакций по подстроке в описании (регулярные выражения).
- Подсчёт операций по категориям.
- Чтение транзакций из JSON, CSV и Excel-файлов.
- Маскировка номеров счетов и карт.
- Форматированный вывод результата.

## Установка

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/Elena-s-94/bank_operations_widget.git
   cd bank_operations_widget
   ```

2. Установи зависимости через Poetry:
   ```bash
   poetry install
   ```

## Запуск

Основной скрипт:
```bash
poetry run python main.py
```

## Модули и функции

### Модуль `generators`

Предоставляет генераторы для эффективной обработки транзакций и генерации данных.

- `filter_by_currency(transactions, currency)` — возвращает генератор транзакций с заданной валютой.
- `transaction_descriptions(transactions)` — возвращает генератор описаний транзакций.
- `card_number_generator(start, end)` — генерирует номера карт в заданном диапазоне.

### Модуль `read_csv_xlsx`

Чтение транзакций из файлов разных форматов.

- `read_csv_file(file_path)` — читает CSV (разделитель `;`), возвращает список словарей.
- `read_excel_file(file_path)` — читает `.xlsx`, возвращает список словарей.

При ошибках (например, файл не найден) возвращается пустой список.

### Модуль `processing`

Обработка транзакций: поиск и подсчёт.

- `process_bank_search(data, search)` — поиск транзакций по строке в описании с использованием регулярных выражений. Возвращает список словарей с совпадениями.
- `process_bank_operations(data, categories)` — подсчёт количества операций по категориям с использованием `Counter` из `collections`. Возвращает словарь `{категория: количество}`.

### Модуль `masks`

Маскировка номеров карт и счетов.

- `get_mask_card_number(card_number)` — маскирует номер карты в формате `XXXX XX** **** XXXX`.
- `get_mask_account(account_number)` — маскирует номер счета, оставляя последние 4 цифры.

### Модуль `widget`

Форматирование и вспомогательные функции.

- `mask_account_card(info)` — маскирует номер счёта или карты в зависимости от типа входных данных (распознаёт по слову «счет»).
- `get_date(date_str)` — преобразует дату из ISO-формата в `DD.MM.YYYY`.

### Модуль `main`

Функция `main()` связывает все функциональности проекта:

- Выбор источника данных (JSON, CSV, XLSX).
- Фильтрация по статусу с валидацией ввода и приведением к единому регистру.
- Сортировка по дате (по возрастанию/убыванию).
- Фильтрация только рублёвых транзакций.
- Поиск по слову в описании через регулярные выражения.
- Форматированный вывод результатов с маскировкой номеров счетов и карт.
