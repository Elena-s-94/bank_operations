  # Bank Operations Widget

Виджет для обработки банковских операций: фильтрация по статусу и сортировка по дате.

## Возможности

- `filter_by_state`: фильтрация транзакций по состоянию (по умолчанию `"EXECUTED"`).
- `sort_by_date`: сортировка транзакций по дате (ISO‑формат), с поддержкой отсутствующих дат.

## Модуль `generators`

Модуль предоставляет генераторы для эффективной обработки транзакций и генерации данных.

### Функции

- `filter_by_currency(transactions, currency)` — возвращает генератор транзакций с заданной валютой.  
  Пример:
  ```python
  usd_transactions = filter_by_currency(transactions, "USD")
  for _ in range(2):
      print(next(usd_transactions))
  
## Новая функциональность: чтение CSV и Excel

В рамках домашнего задания реализована поддержка чтения финансовых операций из файлов разных форматов.

### Реализованные функции

- `read_csv_file(file_path)` — читает транзакции из CSV-файла (разделитель `;`), возвращает список словарей.
- `read_excel_file(file_path)` — читает транзакции из Excel-файла (`.xlsx`), возвращает список словарей.

Обе функции обрабатывают ошибки и возвращают пустой список при проблемах (например, файл не найден).

### Особенности реализации

- Для работы используется библиотека `pandas`.
- Для чтения Excel дополнительно подключена зависимость `openpyxl`.
- Логирование реализовано через стандартный модуль `logging` (логи пишутся в `logs/read_csv_xlsx.log`).
- Покрытие тестами — 100% для нового модуля, все тесты проходят успешно.
